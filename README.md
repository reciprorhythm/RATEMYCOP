# RATEMYCOP.CA

Hello and welcome !! This is the main code repository for ratemycop.ca, a sousveillant shadow library designed for abolition. Developed as part of dissertation research with the Social and Political Thought Program at York University. The website is composed of three modules: rmc-archive (handles browsing and submission of ratings), rmc-rooms (handles peer to peer messaging and file sharing), and cop-co-ssd (a computer vision model for detecting police officers in images/videos). Please note this is an experimental project and the website is currently not accepting uploads, however the code is provided here for your reading and forking pleasure.
