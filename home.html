welcome to ratemycop.ca! an anonymous archive and counter-surveillance platform made for abolition
developed in part through dissertation research with the social and political thought program @ york university
the site is made of three apps all of which can run locally and offline:
a confidential ARCHIVE of user submited ratings of canadian police officers
private and ephemeral p2p CHAT rooms that use a given torrent as rendezvous to send arbitrary data over bitorrent wires, and can also be used to host a mirror of the ratemycop.ca archive
host your own private and ephemeral p2p CHAT room
a computer vision model that DETECTs cops, badges, faces etc. in a given image

This app uses webtorrent to create ephemeral p2p chat rooms that enable users to use a torrent as a rendezvous point at which to share files and messages. It can also be used to mirror or host your own version of the ratemycop archive in the browser. If JSON files containing an array of Cops with ratings-- {id:, first:, last:, rank:, badge:, sal:, "ratings":[{"id":,"time":,"loc":,"txt":, "esc":,"de_esc":,"tags":}]}-- are shared, the app can load these into a temporary archive displayed below the chat. While you are connected to a room, the rating form will have a second upload button labeled "share to room" which will send the rating to all currently connected peers, rather than to the main archive server. In this way users can host a mirror of the site and accept submissions as if they were a server, without needing to install one.
